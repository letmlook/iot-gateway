# IoT 网关：功能总结与待完善列表

## 一、已实现功能总结

### 1. 核心架构（gateway-core）

| 模块 | 功能 | 说明 |
|------|------|------|
| **Bus** | 消息总线 | tokio broadcast 广播 GroupData；`publish`/`subscribe`；容量可配；`subscription_set` 辅助北向过滤；Lagged 打点 |
| **Store** | 内存存储 | 节点/组/标签及 group_tags、tag_location 索引；增删改查、按节点/组查询 |
| **Manager** | 路由与生命周期 | 南/北插件注册；节点创建/删除/启停；南向轮询任务、北向订阅任务；订阅表 CRUD；组/标签 CRUD；`node_setting`（南向运行中改配置自动重启）、`write_tags`；删除南向/组时清理订阅引用；`set_subscriptions` 校验并过滤无效订阅；`apply_snapshot` 后节点重置为 Stopped；`build_snapshot`/`apply_snapshot` |
| **Node** | 节点模型 | NodeConfig（id/name/kind/plugin_name/config）+ NodeState（stopped/running/error） |
| **Persist** | 持久化 | **SQLite**（data.db）：meta/nodes/groups/tags/subscriptions；事务全量写入；版本校验；`load`/`save`/`load_json`；JSON→DB 迁移 |
| **Loader** | 插件加载 | 扫描 plugins_dir 下 .so；FFI 加载南/北插件并注册到 Manager |

### 2. 插件体系（gateway-sdk）

| 能力 | 说明 |
|------|------|
| **SouthPlugin** | open/close/init/uninit、poll_group、list_groups/list_tags、validate_tag、write_tags（可选） |
| **NorthPlugin** | open/close/init/uninit、set_subscriptions、on_group_data |
| **类型** | NodeId/GroupId/TagId（UUID）；DataValue/DataType；Tag/Group；GroupData/GroupSubscription；PluginConfig（JSON）；ConfigSchema/ParamSchema/TagSchema |
| **FFI** | cdylib 导出约定；gateway_south_plugin_* / gateway_north_plugin_*；gateway_plugin_free_string |

### 3. 服务与 API（gateway-server）

| 类别 | 接口 | 说明 |
|------|------|------|
| 健康 | GET /api/health | `{ "status": "ok" }` |
| 插件 | GET /api/plugins/south、north | 列表 (name, description, version) |
| 插件 | GET /api/plugins/south/:name/config_schema、tag_schema | Schema |
| 插件 | GET /api/plugins/north/:name/config_schema | 北向配置 Schema（与南向对称） |
| 节点 | GET/POST /api/nodes；GET/PUT/DELETE /api/nodes/:id | 列表、创建、详情、更新（name）、删除 |
| 节点 | POST /api/nodes/:id/start、stop | 启停 |
| 组 | GET/POST /api/nodes/:id/groups；GET/PUT/DELETE /api/nodes/:id/groups/:gid | 组 CRUD、更新（name/interval_ms/description） |
| 标签 | GET/POST /api/nodes/:id/tags；GET/PUT/DELETE /api/nodes/:id/tags/:tid | 标签 CRUD、单标签详情与更新 |
| 订阅 | GET/PUT /api/nodes/:id/subscriptions | 北向订阅表 |
| 节点 | GET/PUT /api/nodes/:id/setting | 获取/修改插件配置（仅 config） |
| 版本 | GET /api/version | version、build_date、revision |
| 南向 | POST /api/nodes/:id/write_tags | 写 Tag |
| 静态 | /* | 前端 SPA（web/dist）+ fallback |

### 4. 配置与运行

| 项 | 说明 |
|------|------|
| 配置 | GATEWAY_PORT、GATEWAY_DATA_DIR、GATEWAY_STATIC_DIR、GATEWAY_PLUGINS_DIR、RUST_LOG |
| 持久化 | data/data.db（SQLite）；启动加载、变更后 API 层触发保存；无 DB 时有 data.json 则自动迁移 |
| 前端 | Vue3 + Element Plus 管理台；**概览首页**、南向/北向节点、组/标签/订阅、插件、**数据监控（含写值反控）**、系统管理；**节点名称编辑**；北向订阅表显示南向组名 |

### 5. 内置与 .so 插件

| 插件 | 类型 | 说明 |
|------|------|------|
| plugin-sim | 南向 | 模拟设备；默认 group/tags；poll_group 返回值 |
| plugin-mqtt | 北向 | MQTT：QoS 0/1/2、主题模板（\${node_id}/\${group_id}/\${timestamp}）、TLS/SSL、离线缓存与恢复补发、上传格式 group_data/tags_format、retain、keep_alive、setting 重连 |

## 三、待完善列表（按优先级建议）— 已全部实现

### P0：核心能力 ✅

1. **REST API 认证/鉴权** ✅  
   - 已实现：`GATEWAY_TOKEN` 设置后，除 `/api/health`、`/api/metrics` 外需 `Authorization: Bearer <token>`；`GATEWAY_DISABLE_AUTH=1` 可关闭认证。

2. **北向 MQTT 完整功能** ✅  
   - 已实现：plugin-mqtt 使用 rumqttc；配置 host/port/username/password、**topic_template**（变量 \${node_id}/\${group_id}/\${timestamp}）、**qos**（0/1/2）、**retain**、**upload_format**（group_data / tags_format）、**keep_alive_secs**、**cache_memory_size**、**cache_sync_interval_ms**；**ssl** + **ca_file** / **client_cert_file** / **client_key_file** 支持 TLS/双向认证；修改配置后 **setting** 会关闭并重连以应用新配置。

3. **北向离线数据缓存** ✅  
   - 已实现：MQTT 插件内内存缓存（cache_memory_size）；发布失败时入队，收到 ConnAck 时按序重放；配置 `cache_memory_size`（默认 1000）。

### P1：常用能力补全 ✅

4. **南向按需读 Tag（read_tags API）** ✅  
   - 已实现：Manager.read_tags(node_id, tag_ids) 按组调用 poll_group 后过滤；`POST /api/nodes/:id/read_tags` 请求体 `{ "tag_ids": [...] }`，返回 `[(tag_id, value), ...]`。

5. **配置来源扩展** ✅  
   - 已实现：`config/gateway.json` 或 `GATEWAY_CONFIG` 指定路径；加载顺序 默认 → 配置文件 → 环境变量覆盖。

6. **数据目录与备份** ✅  
   - 已实现：save 前若 data.db 存在则复制为 data.db.bak；`GET /api/export` 返回当前快照 JSON。

### P2：可观测与运维 ✅

7. **监控与健康细化** ✅  
   - 已实现：`/api/health` 返回 status、nodes_count、nodes_running、plugins_south、plugins_north；`GET /api/metrics` 返回 Prometheus 格式（gateway_nodes_total、gateway_nodes_running、gateway_plugins_south、gateway_plugins_north）。

8. **日志与排查** ✅  
   - 已实现：请求中间件为每请求生成 X-Request-Id 并写入响应头；tracing Span 记录 request_id。

### P3：生态与扩展 ✅

9. **更多南向驱动**  
   - 按需实现：Modbus、OPC UA 等，实现 SouthPlugin 即可。

10. **北向除 MQTT 外**  
    - 按需实现：HTTP、Kafka 等，实现 NorthPlugin 即可。

11. **插件配置校验** ✅  
    - 已实现：创建节点时若插件提供 config_schema，则 validate_config；返回明确错误信息。

12. **节点/组/标签名称唯一性** ✅  
    - 已实现：Store.group_get_by_name、tag_get_by_name；Manager.group_add/tag_add_validated 校验同节点下组名、同组内标签名唯一，重复返回 Err。
