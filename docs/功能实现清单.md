# 功能实现清单

> 本清单以**代码实现为准**逐项核对，用于排期与外部评审的唯一口径。
> 图例：✅ 已实现 ｜ 🚧 规划中（对应优化路线阶段）｜ ❌ 明确不做
> 最后核对：2026-09-26（阶段一 A1–A4 已实施，状态同步更新）

---

## 一、核心架构

| 能力 | 状态 | 说明 |
|---|:--:|---|
| 插件化框架（南向 / 北向 trait） | ✅ | `SouthPlugin` / `NorthPlugin`，`gateway-sdk` |
| 插件静态链接 | ✅ | `main.rs` `register_builtin_plugins()` |
| 插件 .so 动态加载 | ✅ | 每次 FFI 调用在独立线程执行（插件内 `block_on` 安全）；已用 .dylib 实测加载/采集 |
| 插件 FFI panic 隔离 | ✅ | panic 在**插件侧**被 `catch_unwind` 捕获（`export_*_plugin!` 宏内置），转为该次调用失败；已用故障注入夹具验证（8 个场景） |
| FFI ABI 版本协商 | ✅ | SDK 导出 `gateway_plugin_abi_version()`；宿主加载前校验，不匹配拒绝加载（旧插件告警放行） |
| 插件进程级隔离 | ✅ | `GATEWAY_PLUGIN_ISOLATION=process`：每个插件一个 `gateway-plugin-host` 子进程；插件 abort/段错误只杀子进程，网关自动重启并**重放节点生命周期** |
| 消息总线（tokio broadcast 4096） | ✅ | `Bus`，全量广播 + 北向本地过滤 |
| 总线按组分区 / 背压策略 | ✅ | 按 (南向节点, 组) 分区：投递 O(1)、组间互不影响、`north_filtered` 实测为 0；容量可配；Lagged 按北向节点维度化 |
| 轮询调度器（每个运行中节点一个 task） | ✅ | 固定节拍（周期不因采集耗时漂移）；运行中增删组立即生效；全局并发上限 `GATEWAY_MAX_CONCURRENT_POLLS`；超期计入 `south_poll_overrun` |
| 限并发调度 + 采集超时 + 跳过堆积 | ✅ | 采集超时（`max(3×interval, 5s)`）+ 周期下限（10ms）+ 全局并发上限；周期固定节拍不漂移 |
